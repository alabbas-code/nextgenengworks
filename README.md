# Next Gen Engineering Works website

A responsive static business website for Next Gen Engineering Works.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/` — supplied Next Gen logos and favicon

## Publish with GitHub Pages
1. Create a new **Public** repository named `nextgen-engineering-works`.
2. Upload all files and the `assets` folder from this package to the repository root.
3. Open repository **Settings → Pages**.
4. Set Source to **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the Pages deployment to finish.

The expected project URL under the existing GitHub account is:
`https://alabbas-code.github.io/nextgen-engineering-works/`

## Before launch
- The contact details and email are based on information supplied by the owner.
- The AL ABBAS website link points to the existing AL ABBAS site.
